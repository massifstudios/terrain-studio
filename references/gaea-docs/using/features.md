# Feature Overview

## Terrain creation and realism

- Node-based Infinity Graph for building complete terrain recipes, from first shape to final outputs.
- Extensive node library covering generators, shaping, masking, filtering, simulations, surfacing, utilities, and exports.
- Real-world landform simulations, built around erosion workflows like [Erosion](https://docs.gaea.app/using/using-gaea/understanding-erosion/index.html).
- Surface and material workflows for believable terrain finish, including [Crafting the Surface](https://docs.gaea.app/using/using-gaea/crafting-the-surface/index.html).
- Color workflows from procedural to photographic, including [SatMaps](https://docs.gaea.app/using/using-gaea/colorizing-and-textures/working-with-satmaps.html).

## Build, export, and production pipeline

- End-to-end [Build and Export](https://docs.gaea.app/using/using-gaea/build-and-export/index.html) workflow for repeatable output generation.
- Detailed build diagnostics and outputs via [Build Reports](https://docs.gaea.app/using/advanced-topics/build-swarm/build-reports.html).
- Large-world production via [Tiled Builds](https://docs.gaea.app/using/using-gaea/build-and-export/tiled-builds.html).
- Focused high-resolution production with [Regions](https://docs.gaea.app/using/using-gaea/build-and-export/regions/index.html).
- Mesh pipelines for engines and DCCs via [Mesh Exports](https://docs.gaea.app/using/using-gaea/build-and-export/mesh-exports.html).
- Element-focused exports for downstream compositing and look-dev via [Exporting Elements](https://docs.gaea.app/using/getting-started/basics/exporting-elements.html).

## Speed, iteration, and convenience

- Non-destructive finishing controls with [Modifiers](https://docs.gaea.app/using/using-gaea/managing-graphs/using-modifiers.html).
- Rapid variation systems through [Mutations](https://docs.gaea.app/using/advanced-topics/build-swarm/creating-mutations.html).
- Predictive workflow assistance via [Learning and Predictive System](https://docs.gaea.app/using/advanced-topics/technical-information/learning-and-predictive-system.html).
- Practical approaches for building complex terrains via [Elaborate Terrains](https://docs.gaea.app/using/getting-started/basics/elaborate-terrains.html).
- Tools and habits for scaling big projects via [Managing Graphs](https://docs.gaea.app/using/using-gaea/managing-graphs/index.html).
- Cleaner complex graph wiring patterns using [Portals](https://docs.gaea.app/using/using-gaea/managing-graphs/portals-and-chokepoints.html).

## Automation and pipeline integration

- Headless, high-resolution batch building with [Build Swarm](https://docs.gaea.app/using/advanced-topics/build-swarm/index.html).
- Saved, repeatable production presets through [Profiles and Batch Builds](https://docs.gaea.app/using/advanced-topics/build-swarm/profiles-and-batch-builds.html).
- Full CLI automation for farms and pipelines via [Command Line Automation](https://docs.gaea.app/developers/automation/cli/command-line-automation.html).
- Operational CLI for activation, proxy, safe mode, and diagnostics via [Command-line Interface](https://docs.gaea.app/developers/automation/cli/index.html).
- Automation-friendly filename and path control using [Managing Input and Output](https://docs.gaea.app/developers/automation/building-bridges/managing-input-and-output.html).

## Parametric control and power-user extensibility

- Centralized controls that can drive many properties via [Variables](https://docs.gaea.app/developers/extensibility/scripting-and-expressions/variables.html).
- Per-control value shaping, remapping, and logic using [Expressions](https://docs.gaea.app/developers/extensibility/scripting-and-expressions/expressions.html).
- Scriptable procedural construction inside graphs with [Math Node](https://docs.gaea.app/developers/extensibility/scripting-and-expressions/math-node.html).
- A structured entry point for advanced control systems via [Scripting and Expressions](https://docs.gaea.app/developers/extensibility/scripting-and-expressions/index.html).

## Reliability, troubleshooting, and production readiness

- Bake and cache strategies for large builds using [Baking Nodes](https://docs.gaea.app/using/using-gaea/baking-nodes/index.html).
- Project-wide inspection and cleanup tools via [Data View](https://docs.gaea.app/using/using-gaea/managing-graphs/data-view.html).
- Built-in diagnostics and benchmarking via [Diagnostics](https://docs.gaea.app/using/troubleshooting/diagnostics-watson/index.html).
- Optional CPU-only operation for compatibility and debugging via [CPU Only Mode](https://docs.gaea.app/using/troubleshooting/diagnostics-watson/cpu-only-mode.html).
- Common pitfalls and quick fixes collected in [Common Errors](https://docs.gaea.app/using/troubleshooting/terrains/common-errors.html).

## Import, formats, and interoperability

- Broad interchange support for practical pipelines, documented under [File Formats](https://docs.gaea.app/using/advanced-topics/technical-information/file-formats.html).
- Real-world terrain ingest workflows starting with [Importing Terrains](https://docs.gaea.app/using/using-gaea/importing-terrains/index.html).
- Mesh ingestion workflows for hybrid pipelines via [Importing Meshes](https://docs.gaea.app/using/getting-started/basics/importing-meshes.html).

## Reuse and packaging

- Reusable mini-graphs as single nodes with [Macros](https://docs.gaea.app/developers/extensibility/macros/index.html).
- Macro creation workflow and packaging through [Building Macros](https://docs.gaea.app/developers/extensibility/macros/building-macros.html).
- Guidance for building maintainable, shareable macro libraries via [Macro Best Practices](https://docs.gaea.app/developers/extensibility/macros/best-practices.html).
