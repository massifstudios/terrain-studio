# Diagnostics (Watson)

The Gaea Diagnostics application, nicknamed WATSON, is crucial for diagnosing problems, helping tech support find solutions for you, and for benchmarking your hardware.

![](https://docs.gaea.app/.data/assets/Watson_-_Gaea_Diagnostics_06-12-24-PM.png)

Use Watson to generate a [Diagnostics Package](https://docs.gaea.app/using/troubleshooting/diagnostics-watson/diagnostics-package.html).
