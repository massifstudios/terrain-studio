# CPU Only Mode

In some cases, Gaea may have trouble using your GPU device. Often this is because it is an [unsupported older device](https://docs.gaea.app/install/install-gaea/index.html) or may have outdated drivers.

To enable CPU only mode, start Gaea Diagnostics from the Start Menu. Select "Run Gaea with CPU only" and click "Start".

![](https://docs.gaea.app/.data/assets/Gaea_Diagnostics_11-00-52-AM.png)

This will start Gaea in CPU only mode. It will now remain in CPU only mode, including when running the Gaea Build CLI.

To re-enable multiple device usage, you can go to the [Compute](https://docs.gaea.app/ui/interface/options/compute.html) tab in [Options](https://docs.gaea.app/ui/interface/options/index.html).

![](https://docs.gaea.app/.data/assets/Options_11-01-25-AM.png)
