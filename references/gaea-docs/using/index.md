# Using Gaea

This section covers the core workflows used to build terrains in Gaea. It is designed to help you move from understanding the terrain graph to shaping surfaces, running simulations, preparing builds, and exporting results.

![The Gaea 2.0 User Interface](https://docs.gaea.app/.data/assets/gaea-ui2x.webp)

Whether you are learning the fundamentals or refining a production workflow, these guides will help you understand how Gaea’s main systems fit together.

## In This Section

- [Starter Guide](https://docs.gaea.app/using/getting-started/index.html): Learn the core concepts behind terrain creation in Gaea.
- [Understanding Erosion](https://docs.gaea.app/using/using-gaea/understanding-erosion/index.html): Understand the erosion systems that shape believable landforms.
- [Simulations](https://docs.gaea.app/using/using-gaea/simulations/index.html): Explore natural process simulations such as snow, debris, and other surface effects.
- [Crafting the Surface](https://docs.gaea.app/using/using-gaea/crafting-the-surface/index.html): Shape and refine terrain forms using Gaea’s terrain tools and nodes.
- [Colorizing and Textures](https://docs.gaea.app/using/using-gaea/colorizing-and-textures/index.html): Add colour, masks, and surface detail to support look development and export.
- [Importing Terrains](https://docs.gaea.app/guides/use-in/bridges/gaea2unreal/importing-terrains.html): Bring external terrain data into Gaea for editing, enhancement, or integration.
- [Managing Graphs](https://docs.gaea.app/using/using-gaea/managing-graphs/index.html): Organize, scale, and maintain complex terrain graphs more effectively.
- [Baking Nodes](https://docs.gaea.app/using/using-gaea/baking-nodes/index.html): Cache and bake parts of your graph for faster iteration and more efficient builds.
- [Build and Export](https://docs.gaea.app/using/using-gaea/build-and-export/index.html): Generate final outputs for use in other tools, engines, and production pipelines.

## Suggested Path

If you are new to Gaea, start with [Starter Guide](https://docs.gaea.app/using/getting-started/index.html) and then continue into [Understanding Erosion](https://docs.gaea.app/using/using-gaea/understanding-erosion/index.html) and [Crafting the Surface](https://docs.gaea.app/using/using-gaea/crafting-the-surface/index.html).

If you are already building terrains, you may want to jump directly to [Managing Graphs](https://docs.gaea.app/using/using-gaea/managing-graphs/index.html), [Baking Nodes](https://docs.gaea.app/using/using-gaea/baking-nodes/index.html), or [Build and Export](https://docs.gaea.app/using/using-gaea/build-and-export/index.html) depending on your workflow.
