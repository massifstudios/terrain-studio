# Simulations

Gaea's wide range of simulations help you mimic nature through simulating real-world processes from a both scientific and artistic point-of-view.

![](https://docs.gaea.app/.data/covers/debris.webp)

The most important simulation is [Erosion2](https://docs.gaea.app/reference/nodes/simulate/erosion2.html) as well as the classic [Erosion](https://docs.gaea.app/reference/nodes/simulate/erosion.html). These are augmented by [Thermal2](https://docs.gaea.app/reference/nodes/simulate/thermal2.html), [Crumble](https://docs.gaea.app/reference/nodes/simulate/crumble.html), [Sediments](https://docs.gaea.app/reference/nodes/simulate/sediments.html), and others.

![](https://docs.gaea.app/.data/covers/snow.webp)

[Snow](https://docs.gaea.app/reference/nodes/simulate/snow.html), [Snowfield](https://docs.gaea.app/reference/nodes/simulate/snowfield.html), and [Dusting](https://docs.gaea.app/reference/nodes/simulate/dusting.html) create snow simulations. While [IceFloe](https://docs.gaea.app/reference/nodes/simulate/icefloe.html) can create floating chunks of ice.

[Lake](https://docs.gaea.app/reference/nodes/simulate/lake.html), [Sea](https://docs.gaea.app/reference/nodes/simulate/sea.html), and [Rivers](https://docs.gaea.app/reference/nodes/simulate/rivers.html) create various kinds of water simulations.

![](https://docs.gaea.app/.data/covers/veg.webp)

[Trees](https://docs.gaea.app/reference/nodes/simulate/trees.html) and [Shrubs](https://docs.gaea.app/reference/nodes/simulate/shrubs.html) powerful ways to create vegetation masks driven by real geological factors which can then be used later in DCC apps to create entire forests.

[Debris](https://docs.gaea.app/reference/nodes/simulate/debris.html) creates thousands (even millions) of physics-enabled debris onto your terrain.
