# Using Gaea

The Using Gaea section covers the practical workflows that turn a terrain graph into a finished asset. These pages focus on how the major systems work together: shaping the initial landform, applying erosion and simulations, creating masks and textures, managing larger graphs, and preparing the final build.

Start with [Understanding Erosion](https://docs.gaea.app/using/using-gaea/understanding-erosion/index.html) and [Crafting the Surface](https://docs.gaea.app/using/using-gaea/crafting-the-surface/index.html) when you are building the terrain itself. Move to [Colorizing and Textures](https://docs.gaea.app/using/using-gaea/colorizing-and-textures/index.html) once the landform needs masks, data maps, and color outputs. Use [Managing Graphs](https://docs.gaea.app/using/using-gaea/managing-graphs/index.html) and [Baking Nodes](https://docs.gaea.app/using/using-gaea/baking-nodes/index.html) when the project grows large enough that organization and iteration speed become important.
