# Commands

The **Commands** area provides the actions that launch the build or expose the equivalent command line for automation.

- **Execute Build**: Starts [Build Swarm](https://docs.gaea.app/using/advanced-topics/build-swarm/index.html) for the current file and runs a full-resolution build using the active Build Options.
- **Copy Command Line**: Copies the generated command line for the current file, including fully qualified paths and any variables with their default values.

![](https://docs.gaea.app/.data/assets/command_line_example.png)

See [Command Line Automation](https://docs.gaea.app/developers/automation/cli/command-line-automation.html) for more detail on using the generated command.
