# Binding Variables

Individual properties can be bound to a variable for advanced scenarios such as centralization and automation.

See [Variables](https://docs.gaea.app/developers/extensibility/scripting-and-expressions/variables.html) and [Expressions](https://docs.gaea.app/developers/extensibility/scripting-and-expressions/expressions.html).
