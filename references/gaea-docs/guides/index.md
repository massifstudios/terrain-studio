# Guides Overview

Use this section when you want practical, task-focused help. Guides are organized around production scenarios, integrations, and real workflows instead of individual interface panels or node reference pages.

If [Using Gaea](https://docs.gaea.app/using/index.html) explains how Gaea works, Guides explain how to apply Gaea to a specific production problem.

---

## Start Here

Use Guides when:

- you are moving a terrain into another application
- you are solving a workflow, scale, format, or output problem
- you are building a larger project and need practical production habits
- you want scenario-based advice rather than node-by-node reference

## Main Areas

### Scenarios

Start with [Scenarios](https://docs.gaea.app/guides/scenarios/index.html) when the question is about a production situation: large projects, workflow hygiene, mesh output, naming, baking, or common quality issues.

Useful starting points:

- [Workflow](https://docs.gaea.app/guides/scenarios/workflow/index.html) for graph and output workflow habits
- [Large Projects](https://docs.gaea.app/guides/scenarios/large-projects/index.html) for splitting and managing heavier work
- [Meshes](https://docs.gaea.app/guides/scenarios/meshes/index.html) for mesh-specific output considerations
- [Common Issues](https://docs.gaea.app/guides/scenarios/helpful-info/index.html) for troubleshooting-oriented scenario notes

### Use in DCC Apps

Start with [Universal Instructions](https://docs.gaea.app/guides/use-in/index.html) when you need to move Gaea terrain into another tool and are not sure whether you need a mesh, displacement map, landscape, or bridge workflow.

Use app-specific pages when your target tool matters:

- [Apps](https://docs.gaea.app/guides/use-in/apps/index.html) for DCC app guidance
- [Engines](https://docs.gaea.app/guides/use-in/engines/index.html) for game engine-oriented workflows
- [Bridges](https://docs.gaea.app/guides/use-in/bridges/index.html) for dedicated bridge workflows
- [Gaea2Houdini](https://docs.gaea.app/guides/use-in/bridges/gaea2houdini/index.html) for Houdini integration
- [Gaea2Unreal](https://docs.gaea.app/guides/use-in/bridges/gaea2unreal/index.html) for Unreal integration

## Suggested Paths

If you are exporting for the first time, read [Universal Instructions](https://docs.gaea.app/guides/use-in/index.html) before choosing an app-specific guide.

If something looks wrong after import, start with [Common Issues](https://docs.gaea.app/guides/scenarios/helpful-info/index.html) and then check the guide for your target app or engine.

If a project is becoming slow or hard to manage, start with [Large Projects](https://docs.gaea.app/guides/scenarios/large-projects/index.html) and [Workflow](https://docs.gaea.app/guides/scenarios/workflow/index.html) before changing export settings.
