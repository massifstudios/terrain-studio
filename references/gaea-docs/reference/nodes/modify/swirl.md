# Swirl

Modify › Effect

Shortcode `swi`

Swirl creates a vortex warp on the terrain. Very useful for adding a fluid look.

Swirl creates a vortex warp on the terrain. It can be very useful for adding a fluid look to the terrain.

## When to Use It

Use Swirl when you want a single vortex-like distortion that gives the terrain a fluid or spiral twist.
