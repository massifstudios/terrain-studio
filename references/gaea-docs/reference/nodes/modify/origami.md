# Origami

Modify › Effect

Shortcode `or`

Origami creates a diagonal multifold pattern, and can produce a highly stylized terrain.

The Origami node creates a diagonal multi-fold pattern. It can be used to create a highly stylized terrain. When applied with specific masking, and then processed further with Erosion, the folded structure can produce beautiful, naturalistic results.

## When to Use It

Use Origami when you want deliberate stylized multifold structure rather than natural erosion-driven breakup.

## Properties

**Amount** (`Single`)  
The amount of re-folding to be applied to the terrain. Low values create large folds; high values create tiny folds.

**Seed** (`Int32`)  
The randomization pattern or seed for the node's process. Changing the seed produces different noise patterns.
