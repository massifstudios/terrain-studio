# Blur

Modify › Blur

Shortcode `b`

Blur diffuses sharp shapes and softens the terrain.

Blur diffuses sharp shapes and softens the terrain.

## When to Use It

Use Blur when a terrain or mask is too sharp and needs a softer transition before the next shaping or blending step.
