# Modify Nodes

Modify nodes reshape, filter, remap, warp, or clean up terrain and mask data. Use this family when you already have an input and need to adjust its form, range, sharpness, direction, or spatial behavior.

Start here when you need to:

- clean up unwanted artifacts or fragments
- clamp, normalize, sharpen, blur, or remap height data
- warp, transform, rotate, fold, or reshape an existing terrain
- add controlled post-process changes without replacing the source terrain

Useful starting points:

- [Adjust](https://docs.gaea.app/reference/nodes/modify/adjust.html), [Autolevel](https://docs.gaea.app/reference/nodes/modify/autolevel.html), [Clamp](https://docs.gaea.app/reference/nodes/modify/clamp.html), [Curve](https://docs.gaea.app/reference/nodes/modify/curve.html), and [Threshold](https://docs.gaea.app/reference/nodes/modify/threshold.html) for value and range control
- [Blur](https://docs.gaea.app/reference/nodes/modify/blur.html), [Denoise](https://docs.gaea.app/reference/nodes/modify/denoise.html), [Median](https://docs.gaea.app/reference/nodes/modify/median.html), [Sharpen](https://docs.gaea.app/reference/nodes/modify/sharpen.html), and [SoftClip](https://docs.gaea.app/reference/nodes/modify/softclip.html) for cleanup and filtering
- [Warp](https://docs.gaea.app/reference/nodes/modify/warp.html), [SlopeWarp](https://docs.gaea.app/reference/nodes/modify/slopewarp.html), [DirectionalWarp](https://docs.gaea.app/reference/nodes/modify/directionalwarp.html), [Transform](https://docs.gaea.app/reference/nodes/modify/transform.html), and [Transform3D](https://docs.gaea.app/reference/nodes/modify/transform3d.html) for spatial changes
- [Distance](https://docs.gaea.app/reference/nodes/modify/distance.html), [Fold](https://docs.gaea.app/reference/nodes/modify/fold.html), [GraphicEQ](https://docs.gaea.app/reference/nodes/modify/graphiceq.html), [Shaper](https://docs.gaea.app/reference/nodes/modify/shaper.html), and [ThermalShaper](https://docs.gaea.app/reference/nodes/modify/thermalshaper.html) for stronger shape design
