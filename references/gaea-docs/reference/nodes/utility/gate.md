# Gate

Utility › Routing

Shortcode `g8`

Defines a baking boundary for the graph by forcing all ancestor nodes to be baked.

Node must be baked when executing Hybrid or Tiled builds.

## When to Use It

Use Gate when the graph needs routing, layering, or control logic instead of a new terrain feature.
