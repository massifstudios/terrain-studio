# Reseed

Utility › Routing

Shortcode

Re-randomizes an upstream procedural node by overriding or refreshing its seed behavior.

## When to Use It

Use Reseed when the graph needs routing, layering, or control logic instead of a new terrain feature.

## Properties

**Seed** (`Int32`)
