# DataExtractor

Utility › Utilities

Shortcode `de`

Extracts specific derived data such as boundaries, differences, or Modifier maps from an input.

## When to Use It

Use DataExtractor when the graph needs routing, layering, or control logic instead of a new terrain feature.

## Properties

**Data** (`Enum`)

- **Modifier Mask**
- **Difference**
- **Boundary**
- **Mixer Mask**

**Layer** (`Int32`)

**Level** (`Single`)
