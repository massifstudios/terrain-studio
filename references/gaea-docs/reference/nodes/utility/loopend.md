# LoopEnd

Utility › Routing

Shortcode `le`

Ends a Loop circuit.

## When to Use It

Use LoopEnd when the graph needs routing, layering, or control logic instead of a new terrain feature.

## Properties

**Design Time** (`Boolean`)

**Build Time** (`Boolean`)

**Information** (`Byte`)

**Loops** (`Int32`)  
Number of loops to perform

**Mutate Seeds** (`Boolean`)  
When enabled, the seeds of all nodes within the loop are mutated.

**Seed** (`Int32`)  
The seed for mutation if enabled above.
