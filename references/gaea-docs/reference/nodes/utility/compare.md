# Compare

Utility › Routing

Shortcode `cm`

Compares two inputs and produces a result based on their relative values.

## Official Video

For a video breakdown of this node, see [the official Compare video](https://docs.gaea.app/videos/official/nodes/yt-compare.html).

Compare is a low-level utility that helps you compare two Heightfields.

![](https://docs.gaea.app/.data/assets/compare.png)

## When to Use It

Use Compare when you need to evaluate two inputs against each other instead of just blending them.

## Properties

**A B** (`Single`)  
Ratio of the terrain to compare.

**Colorized** (`Boolean`)  
Show colorized output to signify the modified terrain.

**Perpendicular** (`Boolean`)  
Switch from Horizontal/Stacked to Perpendicular comparison.

**Swap** (`Boolean`)  
Swap A and B inputs.
