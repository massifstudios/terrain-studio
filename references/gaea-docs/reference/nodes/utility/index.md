# Utility Nodes

Utility nodes help organize, route, compare, mask, and control data in a graph. Use this family when the problem is not the terrain shape itself, but how data moves, branches, repeats, or stays manageable.

Start here when you need to:

- route or switch between graph branches
- compare inputs or build helper masks
- manage layers, loops, variables, or reusable graph logic
- keep a complex graph readable and easier to control

Useful starting points:

- [Compare](https://docs.gaea.app/reference/nodes/utility/compare.html), [Mask](https://docs.gaea.app/reference/nodes/utility/mask.html), [Edge](https://docs.gaea.app/reference/nodes/utility/edge.html), and [Accumulator](https://docs.gaea.app/reference/nodes/utility/accumulator.html) for mask and data helpers
- [Layers](https://docs.gaea.app/reference/nodes/utility/layers.html), [Mixer](https://docs.gaea.app/reference/nodes/utility/mixer.html), and [Combine](https://docs.gaea.app/reference/nodes/utility/combine.html) for organizing multiple inputs
- [Gate](https://docs.gaea.app/reference/nodes/utility/gate.html), [Switch](https://docs.gaea.app/reference/nodes/utility/switch.html), [Route](https://docs.gaea.app/reference/nodes/utility/route.html), [LoopBegin](https://docs.gaea.app/reference/nodes/utility/loopbegin.html), and [LoopEnd](https://docs.gaea.app/reference/nodes/utility/loopend.html) for flow control
- [Repeat](https://docs.gaea.app/reference/nodes/utility/repeat.html), [Seamless](https://docs.gaea.app/reference/nodes/utility/seamless.html), and [Reseed](https://docs.gaea.app/reference/nodes/utility/reseed.html) for pattern and variation workflows
- [Math](https://docs.gaea.app/reference/nodes/utility/math.html), [Var](https://docs.gaea.app/reference/nodes/utility/var.html), [MacroPort](https://docs.gaea.app/reference/nodes/utility/macroport.html), and [DataExtractor](https://docs.gaea.app/reference/nodes/utility/dataextractor.html) for technical graph logic
