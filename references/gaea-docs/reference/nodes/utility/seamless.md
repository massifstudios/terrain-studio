# Seamless

Utility › Structure

Shortcode `sls`

Seamless can transform any input terrain or color map into a tileable/repeating pattern.

## When to Use It

Use Seamless when the graph needs routing, layering, or control logic instead of a new terrain feature.

## Properties

**Edge** (`Single`)  
The amount of blending across the opposite edges.

**Shift X** (`Single`)  
Shift blending on the X axis.

**Shift Y** (`Single`)  
Shift blending on the Y axis.

**Preview Tiling** (`Command`)
