# Mixer

Utility › Routing

Shortcode `mx`

Mixer allows layer-based manipulation of color textures and contains in-built masking.

Drop a connection on the node center and you will get an option to add a new port.

## When to Use It

Use Mixer when you need to build a layered terrain color setup from multiple color sources or masks. It is especially useful when height, slope, or custom masks should control where each material appears before the final result is sent downstream to nodes like ColorErosion.

## Properties

**Blend Layers** (`String`)

**Show Simplified** (`Boolean`)

**Preserve Masks** (`Boolean`)

**Add Input** (`Command`)
