# Route

Utility › Routing

Shortcode `ro`

Route chooses the flow of the graph based on the Input/Output ports chosen, and relies on integer input for automation.

Route lets you choose the flow of the graph based on the Input and Output ports chosen. This is an automation node that relies on an integer input.

## When to Use It

Use Route when you need to switch graph flow based on an integer-driven control rather than rewiring nodes by hand.

## Properties

**Choice** (`Int32`)  
The port through which the input should be routed.
