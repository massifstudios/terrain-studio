# Output Nodes

Output nodes prepare terrain data for viewing, baking, rendering, or handoff to another tool. Use this family when the graph is ready to produce a map, preview, mesh, engine export, or final downstream asset.

Start here when you need to:

- preview lighting, ambient occlusion, or presentation renders
- bake derived texture maps from terrain data
- export heightfields, masks, meshes, point clouds, or engine-ready packages
- prepare output for Unity, Unreal, or another production pipeline

Useful starting points:

- [Export](https://docs.gaea.app/reference/nodes/output/export.html) for general file export
- [TextureBaker](https://docs.gaea.app/reference/nodes/output/texturebaker.html) for derived texture maps
- [Mesher](https://docs.gaea.app/reference/nodes/output/mesher.html) for mesh output
- [Unity](https://docs.gaea.app/reference/nodes/output/unity.html) and [Unreal](https://docs.gaea.app/reference/nodes/output/unreal.html) for engine-focused output preparation
- [AO](https://docs.gaea.app/reference/nodes/output/ao.html), [Shade](https://docs.gaea.app/reference/nodes/output/shade.html), [Sunlight](https://docs.gaea.app/reference/nodes/output/sunlight.html), and [LightX](https://docs.gaea.app/reference/nodes/output/lightx.html) for visual preview and render support
