# Derive Nodes

Derive nodes create masks and supporting maps from existing terrain, color, flow, slope, or surface structure. Use this family when you need data that describes the terrain rather than directly changing it.

Start here when you need to:

- extract masks from slope, height, angle, curvature, flow, or color
- generate normal, occlusion, rock, soil, or texture support maps
- create selection data for color, surfacing, masking, or export
- inspect terrain features as reusable data in another part of the graph

Useful starting points:

- [Height](https://docs.gaea.app/reference/nodes/derive/height.html), [Slope](https://docs.gaea.app/reference/nodes/derive/slope.html), [Angle](https://docs.gaea.app/reference/nodes/derive/angle.html), and [Curvature](https://docs.gaea.app/reference/nodes/derive/curvature.html) for core geometric selections
- [FlowMap](https://docs.gaea.app/reference/nodes/derive/flowmap.html) and [FlowMapClassic](https://docs.gaea.app/reference/nodes/derive/flowmapclassic.html) for flow direction and runoff-style data
- [Normals](https://docs.gaea.app/reference/nodes/derive/normals.html) and [Occlusion](https://docs.gaea.app/reference/nodes/derive/occlusion.html) for shading and render support
- [RockMap](https://docs.gaea.app/reference/nodes/derive/rockmap.html), [Soil](https://docs.gaea.app/reference/nodes/derive/soil.html), [TextureBase](https://docs.gaea.app/reference/nodes/derive/texturebase.html), and [Texturizer](https://docs.gaea.app/reference/nodes/derive/texturizer.html) for material and texture masks
- [ColorThreshold](https://docs.gaea.app/reference/nodes/derive/colorthreshold.html) for extracting a mask from a color range
