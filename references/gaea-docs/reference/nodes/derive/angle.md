# Angle

Derive › Aspect

Shortcode `ang`

Angle creates a selection mask covering all areas of the heightfield facing the specified range.

## When to Use It

Use Angle when you need a selection mask covering all areas of the heightfield facing the specified range.

## Properties

**Azimuth** (`Single`)  
The direction from which to start the selection.

**Range** (`Float2`)

**Falloff** (`Single`)  
The soft falloff at the maximum angle.
