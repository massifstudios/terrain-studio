# Colorize Nodes

Colorize nodes create, process, split, combine, and weather color data. Use this family when the terrain needs visual color, material palette work, or channel operations for downstream texturing.

Start here when you need to:

- create a first-pass terrain color map
- layer, tint, split, merge, or process color channels
- make color follow terrain flow, sediment, or weathering behavior
- prepare color data for texturing, rendering, or export

Useful starting points:

- [SatMap](https://docs.gaea.app/reference/nodes/colorize/satmap.html) and [SuperColor](https://docs.gaea.app/reference/nodes/colorize/supercolor.html) for terrain-aware base color
- [ColorErosion](https://docs.gaea.app/reference/nodes/colorize/colorerosion.html) and [Weathering](https://docs.gaea.app/reference/nodes/colorize/weathering.html) for weathered or flow-aware color passes
- [WaterColor](https://docs.gaea.app/reference/nodes/colorize/watercolor.html) for water-specific color
- [RGBMerge](https://docs.gaea.app/reference/nodes/colorize/rgbmerge.html), [RGBSplit](https://docs.gaea.app/reference/nodes/colorize/rgbsplit.html), [HSL](https://docs.gaea.app/reference/nodes/colorize/hsl.html), [Gamma](https://docs.gaea.app/reference/nodes/colorize/gamma.html), and [Tint](https://docs.gaea.app/reference/nodes/colorize/tint.html) for channel and color adjustments
- [Synth](https://docs.gaea.app/reference/nodes/colorize/synth.html) and [CLUTer](https://docs.gaea.app/reference/nodes/colorize/cluter.html) for source-driven or lookup-based color workflows
