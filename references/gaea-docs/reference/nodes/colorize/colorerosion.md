# ColorErosion

Colorize › Erosion

Shortcode `cx`

Applies erosion-style transport and deposition to color data, creating more natural weathered color variation.

## When to Use It

Use ColorErosion when you already have a terrain color setup and want it to feel more natural, weathered, and terrain-aware.
