# Uplift

Terrain › Landscape

Shortcode

Creates tectonic-style uplift by raising and shaping large terrain masses.

Node must be baked when executing Hybrid or Tiled builds.

## When to Use It

Use Uplift when you need tectonic-style uplift by raising and shaping large terrain masses.
