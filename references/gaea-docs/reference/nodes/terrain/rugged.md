# Rugged

Terrain › Landscape

Shortcode `gg`

Rugged is a very powerful primitive node that creates a strong, rocky surface for any terrain while preserving overall shape.

Node must be baked when executing Hybrid or Tiled builds.

Rugged is a very powerful Landscape node that creates a strong, rocky surface for any terrain while preserving overall shape. This enables you to add tremendous amounts of details to any surface.

## When to Use It

Use Rugged when you want a large landform that already carries a strong rocky character before you begin later erosion or surface detailing.
