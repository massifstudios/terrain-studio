# Ridge

Terrain › Landscape

Shortcode `ri`

Ridge creates a rugged ridgeline with multiple fractures and rock shearing.

Node must be baked when executing Hybrid or Tiled builds.

## When to Use It

Use Ridge when you need a rugged ridgeline with multiple fractures and rock shearing.

![](https://docs.gaea.app/.data/assets/Ridge_VD.png)

## Properties

**Scale** (`Single`)  
Scale of the ridgeline.

**Height** (`Single`)  
Sets the height of the ridge.

**Definition** (`Single`)  
Adds details on the ridgelines.

**Seed** (`Int32`)  
The randomization pattern or seed for the node's process.

**Scale X** (`Single`)  
The non-uniform scale of the X axis.

**Scale Y** (`Single`)  
The non-uniform scale of the Y axis.
