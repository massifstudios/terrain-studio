# Sand

Surface › Superficial

Shortcode `sd`

Sand creates medium and small level sand patterns. It can also be used to simulate dunes.

Node must be baked when executing Hybrid or Tiled builds.

## When to Use It

Use Sand when broad landforms are already in place and the terrain needs dune-like or blown-sand surface patterns.
