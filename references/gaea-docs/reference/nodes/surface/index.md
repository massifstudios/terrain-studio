# Surface Nodes

Surface nodes add terrain character, breakup, stratification, and material-like detail. Use this family after the main landform exists and you need the surface to feel rocky, sandy, layered, cracked, weathered, or more visually complex.

Start here when you need to:

- add rock, sand, stones, terraces, or surface breakup
- make a clean terrain feel less procedural
- build stratified or fractured terrain detail
- create surface patterns that respond to the existing terrain shape

Useful starting points:

- [Terraces](https://docs.gaea.app/reference/nodes/surface/terraces.html), [FractalTerraces](https://docs.gaea.app/reference/nodes/surface/fractalterraces.html), [Stratify](https://docs.gaea.app/reference/nodes/surface/stratify.html), and [Sandstone](https://docs.gaea.app/reference/nodes/surface/sandstone.html) for layered forms
- [Rockscape](https://docs.gaea.app/reference/nodes/surface/rockscape.html), [RockNoise](https://docs.gaea.app/reference/nodes/surface/rocknoise.html), [Outcrops](https://docs.gaea.app/reference/nodes/surface/outcrops.html), [Stones](https://docs.gaea.app/reference/nodes/surface/stones.html), and [Roughen](https://docs.gaea.app/reference/nodes/surface/roughen.html) for rocky character
- [Sand](https://docs.gaea.app/reference/nodes/surface/sand.html), [Distress](https://docs.gaea.app/reference/nodes/surface/distress.html), [Craggy](https://docs.gaea.app/reference/nodes/surface/craggy.html), [Shatter](https://docs.gaea.app/reference/nodes/surface/shatter.html), and [Shear](https://docs.gaea.app/reference/nodes/surface/shear.html) for breakup and erosion-like detail
- [Bomber](https://docs.gaea.app/reference/nodes/surface/bomber.html), [GroundTexture](https://docs.gaea.app/reference/nodes/surface/groundtexture.html), [Pockmarks](https://docs.gaea.app/reference/nodes/surface/pockmarks.html), [Steps](https://docs.gaea.app/reference/nodes/surface/steps.html), and [Grid](https://docs.gaea.app/reference/nodes/surface/grid.html) for specialized surface structure
