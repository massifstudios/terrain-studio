# Steps

Surface › Terrace

Shortcode `ste`

Creates stepped formations and hard terrace-like breaks in the terrain.

## When to Use It

Use Steps when you need stepped formations and hard terrace-like breaks in the terrain.

## Visual Direction

## Properties

**Scale** (`Single`)  
Controls the overall size and spacing of the steps. Higher values produce larger, more widely spaced terraces, while lower values create finer, closely packed steps.

**Density** (`Single`)  
Determines the number of steps or terraces within the terrain. Increasing density results in more steps, creating a more detailed and intricate terraced effect.

**Seed** (`Int32`)  
Sets the random seed for the step pattern. Changing the seed generates a different arrangement of steps while keeping other settings the same.
