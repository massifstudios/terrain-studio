# Terraces

Surface › Terrace

Shortcode `st`

Creates stepped terrace formations from the terrain.

## When to Use It

Use Terraces when you need stepped terrace formations from the terrain.

## Visual Direction

## Properties

**Terraces** (`Int32`)  
Controls the number and spacing of terrace steps applied to the terrain. Increasing this value creates more distinct, layered steps.

**Uniformity** (`Single`)  
Adjusts the consistency of terrace step heights. Higher uniformity produces evenly spaced terraces, while lower values introduce variation.

**Steepness** (`Single`)  
Sets the vertical sharpness of each terrace step. Higher steepness results in more abrupt transitions between steps.

**Intensity** (`Single`)  
Determines the overall strength of the terrace effect. Higher intensity makes the terraces more pronounced in the terrain.

**Seed** (`Int32`)  
Defines the randomization seed for procedural terrace generation. Changing the seed produces different terrace patterns.
