# Primitive Nodes

Primitive nodes create foundational shapes, gradients, patterns, and noise sources. Use this family when you need a starting form, reusable mask, procedural signal, or shape generator at the beginning of a graph.

Start here when you need to:

- create a clean shape or gradient
- generate base noise for later erosion or surface work
- build procedural masks and reusable patterns
- import a file, object, or tile source into the graph

Useful starting points:

- [Noise](https://docs.gaea.app/reference/nodes/primitive/noise.html), [Perlin](https://docs.gaea.app/reference/nodes/primitive/perlin.html), [MultiFractal](https://docs.gaea.app/reference/nodes/primitive/multifractal.html), and [Cellular](https://docs.gaea.app/reference/nodes/primitive/cellular.html) for general procedural noise
- [Shape](https://docs.gaea.app/reference/nodes/primitive/shape.html), [Cone](https://docs.gaea.app/reference/nodes/primitive/cone.html), [Hemisphere](https://docs.gaea.app/reference/nodes/primitive/hemisphere.html), [LinearGradient](https://docs.gaea.app/reference/nodes/primitive/lineargradient.html), and [RadialGradient](https://docs.gaea.app/reference/nodes/primitive/radialgradient.html) for simple forms
- [Cracks](https://docs.gaea.app/reference/nodes/primitive/cracks.html), [Voronoi](https://docs.gaea.app/reference/nodes/primitive/voronoi.html), [Gabor](https://docs.gaea.app/reference/nodes/primitive/gabor.html), and [LineNoise](https://docs.gaea.app/reference/nodes/primitive/linenoise.html) for stronger pattern character
- [File](https://docs.gaea.app/reference/nodes/primitive/file.html), [Object](https://docs.gaea.app/reference/nodes/primitive/object.html), and [TileInput](https://docs.gaea.app/reference/nodes/primitive/tileinput.html) for external or tiled inputs
