# Draw

Primitive › Basic

Shortcode `vm`

Draw draws entire mountain ranges in the shape you choose.

Node must be baked when executing Hybrid or Tiled builds.

## When to Use It

Use Draw when you need draws entire mountain ranges in the shape you choose.
