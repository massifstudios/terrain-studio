# LinearGradient

Primitive › Gradient

Shortcode `lg`

Generates a straight linear gradient across the terrain.

Node must be baked when executing Hybrid or Tiled builds.

## When to Use It

Use LinearGradient when you need a straight linear gradient across the terrain.
