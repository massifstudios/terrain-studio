# Simulate Nodes

Simulate nodes apply process-based terrain changes such as erosion, snow, water, vegetation, debris, or deposition. Use this family when the terrain should react as if shaped by natural forces rather than only by geometric filters.

Start here when you need to:

- erode or weather an existing terrain
- add snow, ice, debris, rivers, lakes, or sea behavior
- create vegetation or growth-style surface coverage
- use simulation as a grounding pass after terrain generation

Useful starting points:

- [Erosion](https://docs.gaea.app/reference/nodes/simulate/erosion.html), [Erosion2](https://docs.gaea.app/reference/nodes/simulate/erosion2.html), [EasyErosion](https://docs.gaea.app/reference/nodes/simulate/easyerosion.html), [Wizard](https://docs.gaea.app/reference/nodes/simulate/wizard.html), and [Wizard2](https://docs.gaea.app/reference/nodes/simulate/wizard2.html) for erosion workflows
- [Thermal](https://docs.gaea.app/reference/nodes/simulate/thermal.html), [Thermal2](https://docs.gaea.app/reference/nodes/simulate/thermal2.html), [Debris](https://docs.gaea.app/reference/nodes/simulate/debris.html), [Scree](https://docs.gaea.app/reference/nodes/simulate/scree.html), and [Sediments](https://docs.gaea.app/reference/nodes/simulate/sediments.html) for breakdown and deposition
- [Lake](https://docs.gaea.app/reference/nodes/simulate/lake.html), [Rivers](https://docs.gaea.app/reference/nodes/simulate/rivers.html), [Sea](https://docs.gaea.app/reference/nodes/simulate/sea.html), and [HydroFix](https://docs.gaea.app/reference/nodes/simulate/hydrofix.html) for water-related terrain behavior
- [Snow](https://docs.gaea.app/reference/nodes/simulate/snow.html), [Snowfield](https://docs.gaea.app/reference/nodes/simulate/snowfield.html), [Glacier](https://docs.gaea.app/reference/nodes/simulate/glacier.html), and [IceFloe](https://docs.gaea.app/reference/nodes/simulate/icefloe.html) for cold-climate effects
- [Trees](https://docs.gaea.app/reference/nodes/simulate/trees.html) and [Shrubs](https://docs.gaea.app/reference/nodes/simulate/shrubs.html) for vegetation-style simulation
