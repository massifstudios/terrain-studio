# Sediments

Simulate › Erosion

Shortcode `sed`

Sediments creates a thick layer of generic sedimentation on top of the terrain, which can be used for sand or snow.

## When to Use It

Use Sediments when you need a thick layer of generic sedimentation on top of the terrain, which can be used for sand or snow.
