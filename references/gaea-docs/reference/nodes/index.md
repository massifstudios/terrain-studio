# Node Families

Browse the Gaea node library by family. Each family groups related processors so you can compare similar tools quickly and jump to the exact node you need.

Use this page when you know the kind of work you want a node to do, but not the exact node name yet.

## Choose a Family

| Family | Best starting point when you need to... |
| --- | --- |
| [Terrain](https://docs.gaea.app/reference/nodes/terrain/index.html) | Create a large terrain base such as mountains, islands, ridges, dunes, craters, or volcanoes. |
| [Primitive](https://docs.gaea.app/reference/nodes/primitive/index.html) | Generate simple shapes, gradients, masks, patterns, noises, or reusable graph inputs. |
| [Simulate](https://docs.gaea.app/reference/nodes/simulate/index.html) | Add natural process behavior such as erosion, snow, debris, water, trees, or vegetation. |
| [Surface](https://docs.gaea.app/reference/nodes/surface/index.html) | Add visual surface character such as terraces, rocks, sand, stones, cracks, or stratified detail. |
| [Modify](https://docs.gaea.app/reference/nodes/modify/index.html) | Reshape, filter, warp, clamp, sharpen, smooth, or clean up an existing terrain or mask. |
| [Derive](https://docs.gaea.app/reference/nodes/derive/index.html) | Extract masks and supporting maps from height, slope, flow, curvature, normals, color, or surface structure. |
| [Colorize](https://docs.gaea.app/reference/nodes/colorize/index.html) | Build terrain color, split or merge channels, apply palettes, or weather color through terrain flow. |
| [Utility](https://docs.gaea.app/reference/nodes/utility/index.html) | Route data, organize graphs, compare inputs, manage masks, or add reusable graph logic. |
| [Output](https://docs.gaea.app/reference/nodes/output/index.html) | Preview, render, bake, export, or prepare outputs for engines, DCC apps, and production pipelines. |

## How to Use Node Pages

Most node pages are designed for fast lookup first. A finished page should tell you what the node does, when to use it, what visual result to expect, and which properties matter most.

Some node pages include visual reference images in the foldout to show the intended result or comparison at a glance.
