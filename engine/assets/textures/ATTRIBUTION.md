# Surface textures

Albedo tiles the viewport lays over splat weights. Every file here is the 1K
JPG diffuse map of a Poly Haven texture (https://polyhaven.com), released
under CC0 1.0 (public domain). File names are the Poly Haven asset ids.

To add one: drop a `.jpg` or `.png` into this directory (or into
`<user data>/assets/textures/`) and restart the engine; the file name becomes
the option in every texture parameter.
